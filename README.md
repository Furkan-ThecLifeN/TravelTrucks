🚐 TravelTrucks – Camper Rental Web Application

TravelTrucks is a modern camper rental application that allows users to explore camper models, filter them by various criteria, and add their favorites. Built with React, Redux Toolkit, and Vite, it offers a fast and user-friendly interface.

✨ Key Features

🔎 Advanced filtering: Search by location, form, transmission, and equipment features
❤️ Favorites system with LocalStorage synchronization
📄 Detailed camper pages: Photo gallery, technical information, and user reviews
⚡ High performance with Vite + React
🔄 Dynamic data via API using MockAPI for realistic backend simulation

🛠️ Technologies Used

React

Redux Toolkit

Vite

Axios

React Router

CSS Modules

📂 Project Purpose

TravelTrucks aims to help users quickly find the right camper for their needs. With its filtering system and clean interface, it delivers a streamlined experience similar to a real rental platform.
